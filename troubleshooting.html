Troubleshooting

Stable compiler rejects a nightly option

An older wrapper always added -Zallow-features, even with a stable compiler pin. Update to the compatibility fix and run the wrapper tests. Do not enable RUSTC_BOOTSTRAP or silently remove the nightly allowlist.

rustup show active-toolchain
python3 .cargo/test_strict_rustc.py

GNU timeout is unavailable

Check timeout --version. On macOS, Homebrew coreutils supplies gtimeout and a gnubin directory. Add the correct path to the shell or scheduled job's environment. launchd may not inherit an interactive shell's PATH.

macOS retains an active or unverified root

An open file, current directory or mapped executable may retain an entire pruning root. Required capability snapshots must also be complete. Close only your own completed fixture handles when testing; do not stop services or remove protection checks to force deletion.

An inaccessible process or a process starting after the snapshot remains a visibility limit. A snapshot is not an atomic lock on other processes.

A worktree remains

Inspect the category-specific retained reason and selected policy. Missing registrations require their own opt-in. Old build output does not make an unmerged or recovery-bearing checkout eligible.

--discard-stale-workspaces authorizes loss of old unfinished data; do not add it merely to suppress a retained reason.

JJ version or repository-format mismatch

Check the native CLI version, locked JJ library version and repository format. Use fixtures created by supported tools. Unreadable membership/store evidence retains workspaces. Do not rewrite a real store for an unverified build.

A build reaches its budget

Keep the stopped log and closure receipt. Separate build-cache growth from shared-volume changes before choosing a measured next step. Reusing a cache can reduce demand; do not reset counters or increase an approved cap without the required authorization.

Preview differs from execution

They capture different live snapshots. Execution can retain changed candidates, or an earlier workspace removal can release a later branch candidate. Preview is not a saved transaction. Review category counters rather than summing overlapping estimates.

Physical space differs from reported bytes

Logical lengths do not include sparse allocation, compression, shared blocks or external hard links. Measure filesystem availability independently when physical reclamation matters.
