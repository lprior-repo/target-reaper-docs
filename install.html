Installation

Build Target Reaper natively on the platform where you will run it. The primary packaging targets are Apple-silicon macOS and x86-64 Linux.

Requirements

Tool Purpose
Rust 1.99.1 through rustup Compiler pinned by rust-toolchain.toml
C toolchain/linker Native dependencies and final linking
Git Repository/worktree operations and fixtures
GNU timeout Bounded external commands
Native jj, for JJ cleanup Workspace inspection and exact-name operations

Use the pinned compiler. Do not set RUSTC_BOOTSTRAP or remove the wrapper to work around build failures.

macOS

Install Apple's command-line tools if missing. With Homebrew available:

brew install git coreutils
brew install jj # optional unless you use JJ workspace cleanup
export PATH="$(brew --prefix coreutils)/libexec/gnubin:$PATH"
timeout --version
git --version
jj --version # when JJ support is required

Homebrew supplies GNU timeout as gtimeout and inside its gnubin directory. Derive the actual prefix with brew --prefix coreutils; Apple-silicon and Intel Homebrew installations use different prefixes.

Mac cleanup uses native lsof, mount information and descriptor-relative filesystem operations. Required capability evidence must be available and complete before eligible cleanup proceeds.

Linux

Debian/Ubuntu:

sudo apt-get update
sudo apt-get install build-essential git coreutils pkg-config

Arch Linux:

sudo pacman -S --needed base-devel git coreutils pkgconf

Install native jj if needed. Verify that timeout --version identifies GNU coreutils. Linux process/filesystem checks depend on the native kernel and visible process information.

Compile the checkout

The current Mac compatibility corrections are on fix/macos-main-8e73fe0, based on main at 8e73fe0, pending integration. Use that branch for the verified development snapshot.

git clone --branch fix/macos-main-8e73fe0 https://github.com/lprior-repo/target-reaper.git
cd target-reaper
rustup show active-toolchain
cargo build --release --locked
./target/release/target-reaper --version

The source repository is private. Clone and release downloads require an authorized account; access to public documentation does not grant source access.

Install for your user

cargo install --path . --locked
command -v target-reaper
target-reaper --version

Ensure Cargo's bin directory is on your PATH. Installing the binary does not schedule cleanup. Review a narrow preview before using execution or automation.

Archives

Choose the archive matching your OS/architecture, check its SHA-256 manifest, and inspect its build provenance. See release packaging. An archive's existence does not prove that native tests passed for its commit.
