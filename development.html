Development and verification

Use an owned disposable checkout and fixture roots. Never point tests or an unverified build at personal repositories, home directories or real cleanup data.

Compiler policy

rust-toolchain.toml pins Rust 1.99.1 with rustfmt, Clippy and LLVM tools. Stable Rust rejects unstable feature attributes. For an explicitly selected nightly/dev compiler, .cargo/strict-rustc.sh enforces exactly portable_simd,try_blocks, rejects conflicts and covers dependency compiler probes.

RUSTC_BOOTSTRAP is rejected. Toolchain and policy changes are reviewable changes, not dependency workarounds.

Fast checks

python3 .cargo/test_strict_rustc.py
cargo fmt --check
cargo check --workspace --all-targets --all-features --locked
cargo clippy --workspace --lib --bins --examples --all-features --locked -- -D warnings

All-targets checking compiles tests, examples and benches; it does not execute Criterion benchmarks. Strict source linting is separate from test implementation style.

Fixture tests

CLI fixtures must use the binary path supplied by Cargo/nextest at runtime, and fail when that binding is missing. Do not select an installed binary from PATH. See nextest runtime variables.

Install cargo-nextest from its official distribution, then:

CARGO_BUILD_JOBS=2 cargo nextest run --workspace --lib --tests \
  --all-features --locked --test-threads 2 --no-fail-fast

Use isolated HOME/TMPDIR, isolated VCS config, no network during execution, and writes limited to owned fixtures/build output. Keep foreign jobs intact. Resource supervision must confirm exit/reap and owned descendant closure.

Do not walk live fixture candidates to measure space: the monitor's directory descriptors can correctly trigger activity retention. Record owned build-cache growth separately from shared-volume changes, while preserving the shared free-space floor.

For constrained builds, disable debug symbols and incremental output without disabling runtime assertions or overflow checks:

CARGO_BUILD_JOBS=1 CARGO_INCREMENTAL=0 \
  CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 \
  cargo nextest run --workspace --lib --tests --all-features --locked --test-threads 2

The hosted Mac harness resolves the selected Apple SDK and real compiler/archive tools read-only, then supplies their absolute paths inside the sandbox. It records macos-toolchain.json; it does not invoke xcrun or allow its lookup cache outside the fixture. The selected SDK default deployment target is used unless a valid explicit target is supplied.

Declare budgets before execution. Stopped or partial runs remain incomplete, and cache reuse does not turn them into passing evidence.

Native OS coverage

Run Mac fixtures on macOS and Linux fixtures on Linux. Target checks do not validate another kernel's process/filesystem behavior. Do not substitute Docker/VM execution when a task requires an authorized native executor.

test-plan.md, test-plan-review.md and test-suite-review.md record broader contracts and historical evidence. Read their commit/scope and blocked cases before interpreting counts.

Assurance checks

Tools include audit, deny, vet, geiger, machete, feature combinations and scoped mutations. Preserve real exit statuses and output. The checked-in Cargo license policy accepts MIT, Apache-2.0, Unicode-3.0, BSD-3-Clause, Zlib and MPL-2.0 for normal/build dependencies.

Do not add blanket exemptions or invent audits. Vet imports, publisher attestations and criteria need approved provenance before coverage can be claimed. Mutation inventories are candidates, not execution: require a baseline and classify caught, missed, unviable and interrupted outcomes.

Build these docs

Python 3.10 or newer is required:

python3 -m venv .venv-docs
.venv-docs/bin/pip install -r docs/requirements.txt
.venv-docs/bin/python scripts/build_docs.py --output target/devdocs
.venv-docs/bin/python scripts/check_docs.py target/devdocs
python3 -m http.server 8000 --directory target/devdocs

The public site contains documentation only. It does not make the private source repository or release assets public.
