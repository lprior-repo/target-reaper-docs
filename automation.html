Automation on Mac and Linux

Schedule only a command you have reviewed manually. The examples here run previews. Adding --execute changes their authority and must be an intentional local decision.

Use the same lock path for scheduled and manual runs. Native command lookup must work in the scheduler's environment; interactive shell startup files may not be loaded.

macOS: launchd

Create a user LaunchAgent only after replacing every /Users/YOU path below with an absolute path for your account. launchd does not expand $HOME inside ProgramArguments.

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>local.target-reaper.preview</string>
  <key>ProgramArguments</key><array>
    <string>/Users/YOU/.cargo/bin/target-reaper</string>
    <string>--root</string><string>/Users/YOU/src</string>
    <string>--age-days</string><string>7</string>
    <string>--min-size</string><string>100M</string>
    <string>--list</string>
  </array>
  <key>EnvironmentVariables</key><dict>
    <key>PATH</key><string>/opt/homebrew/opt/coreutils/libexec/gnubin:/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin</string>
  </dict>
  <key>StartInterval</key><integer>86400</integer>
  <key>StandardOutPath</key><string>/Users/YOU/Library/Logs/target-reaper-preview.log</string>
  <key>StandardErrorPath</key><string>/Users/YOU/Library/Logs/target-reaper-preview.err</string>
</dict></plist>

Adjust the Homebrew prefix on Intel Macs. Save the file as ~/Library/LaunchAgents/local.target-reaper.preview.plist, validate it, then explicitly load it:

plutil -lint "$HOME/Library/LaunchAgents/local.target-reaper.preview.plist"
launchctl bootstrap "gui/$(id -u)" "$HOME/Library/LaunchAgents/local.target-reaper.preview.plist"

To stop the schedule:

launchctl bootout "gui/$(id -u)" "$HOME/Library/LaunchAgents/local.target-reaper.preview.plist"

Linux: systemd user timer

~/.config/systemd/user/target-reaper-preview.service:

[Unit]
Description=Preview stale Rust build artifacts

[Service]
Type=oneshot
ExecStart=%h/.cargo/bin/target-reaper --root %h/src --age-days 7 --min-size 100M --list

~/.config/systemd/user/target-reaper-preview.timer:

[Unit]
Description=Daily Target Reaper preview

[Timer]
OnCalendar=daily
Persistent=true

[Install]
WantedBy=timers.target

After reviewing the files:

systemctl --user daemon-reload
systemctl --user enable --now target-reaper-preview.timer
systemctl --user status target-reaper-preview.timer
journalctl --user -u target-reaper-preview.service

To stop it, use systemctl --user disable --now target-reaper-preview.timer.

Before authorizing scheduled deletion

Review the exact roots, age, size, exclusions, lock path and category flags. Confirm that scheduler logs are readable and retained. A daily schedule does not justify --discard-stale-workspaces or broad per-file scope.

Installing the binary or building these docs does not create any schedule. No cleanup service is enabled by this repository automatically.
